# tpt-concord-core

Core IDs, assurance levels, assumptions, scopes, versions and the Assurance Graph.

Part of [TPT Concord](https://github.com/tpt-solutions/tpt-concord) — the evidence and conformance layer that
connects specifications, claims, proofs, tests and release decisions.

## Overview

Core types for TPT Concord: identifiers, assurance levels, assumptions,
scopes, versions, and the Assurance Graph.

Everything Concord builds on starts here: first-class machine-readable
objects for *what we claim*, *why we claim it*, *under which assumptions*,
and *what remains unproven*.
