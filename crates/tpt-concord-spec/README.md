# tpt-concord-spec

Specification representation: pre/postconditions, invariants, transitions, effects, bounds.

Part of [TPT Concord](https://github.com/tpt-solutions/tpt-concord) — the evidence and conformance layer that
connects specifications, claims, proofs, tests and release decisions.

## Overview

`tpt-concord-spec` — specification representation.

Provides machine-readable specifications with preconditions,
postconditions, invariants, state transitions, effects, resource bounds
and permitted behaviours, over a small serializable predicate language.
